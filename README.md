# Smart Parking Platform

Semester project for CIS 4374 – Software Requirements Specification (SRS)

## Project Overview
This project simulates the planning and documentation of a Smart Parking Platform. 
The system helps drivers locate, reserve, and pay for parking spaces in real time, 
and provides operators with tools for occupancy monitoring and pricing management.
